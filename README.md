# 🎯 Adivina el Número con Vite

Mini proyecto desarrollado como parte del módulo de **Introducción a Vite de DEV.F**.

## 📌 Descripción

Juego interactivo desarrollado con JavaScript y Vite, en el que el usuario debe adivinar un número aleatorio entre 1 y 100.

La aplicación proporciona pistas para ayudar al jugador, indicando si el número secreto es mayor o menor al ingresado.

## ⚙️ Funcionalidades

- Generar un número aleatorio entre 1 y 100.
- Permitir al usuario ingresar un número para intentar adivinarlo.
- Mostrar pistas según el número ingresado.
- Validar que los valores estén dentro del rango permitido.
- Contar los intentos realizados.
- Mostrar un mensaje al adivinar correctamente.
- Reiniciar el juego con un nuevo número secreto.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js y npm
- Vite

## 💻 Ejecución

Es necesario tener instalado Node.js.

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar las dependencias:

   `npm install`

4. Iniciar el servidor de desarrollo:

   `npm run dev`

5. Abrir en el navegador la dirección local que muestre Vite.

**Nota para PowerShell:** Si la ejecución de `npm` está bloqueada, utilizar `npm.cmd install` y `npm.cmd run dev`.

## 🎯 Objetivo

Practicar la creación de proyectos utilizando Vite y JavaScript Vanilla, implementando una aplicación interactiva mediante eventos, manipulación del DOM y módulos de JavaScript.
